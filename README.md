# Sparkium: Monorepo

This repository contains the codebase of Sparkium:

- Apps:
  - [website](apps/website): The official Sparkium website, showcasing the project and providing resources for users.
- Libs:
  - [types](libs/types): Type definitions and JSON schemas used across the Sparkium project, ensuring consistency and type safety.

## Getting started

As a **content creator**, check out the [website](https://sparkium.org) to learn how to use Sparkium for creating your educational content.

As a **developer**, have a look at the [contributing guidelines](CONTRIBUTING.md).
